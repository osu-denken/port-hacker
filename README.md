# PORT_HACKER
ネットワークのプロトコル名と対応する標準ポート番号を、ハッキングゲーム感覚で楽しく、スピーディに学べるブラウザ向けのクイズゲームです。
サイバーパンク風のレトロターミナルUI、手触り感のあるアニメーション、制限時間による緊張感、そして詳細な学習解説機能を備えており、インフラエンジニアやプログラマーの基礎知識の確認・定着に最適です。

## 特徴とゲームシステム

- 3つの難易度モード
  初心者向けの基礎的なノーマルから、インフラ系を網羅するハード、そして開発やゲームサーバーまで網羅するおまけまで幅広く用意されています。
- 選べる問題数とエンドレスモード
  クイックに遊べる10問、標準的な20問、じっくり挑む30問のほか、ライフが尽きるまで挑戦し続けるサバイバル形式のエンドレスを選択可能です。
- 逆引き問題と完全な重複防止
  プロトコル名からポートを当てる通常問題に加え、ランダムでポート番号からプロトコル名を当てる逆引き問題が出現します。また、問題プールはシャッフルされて消費されるため、同じ問題が連続しにくい構造です。
- 学習を深める解説パネル
  解答直後に、そのポートやプロトコルに関する詳細な解説パネルが表示されるため、遊ぶたびにネットワークの知識が深まります。
- コンボとスコアアタック
  連続正解や、解答にかかった残り時間に応じてスコアが大きく跳ね上がります。高コンボ時には紙吹雪の演出が発生します。
- キーボード完全対応
  マウス操作はもちろん、キーボードの数字キーによる即時回答や、解説画面のキー入力スキップに対応しており、ハッカーのようにサクサク快適にプレイできます。

## ゲームモード詳細

| モード名 | 対象範囲 | 概要・出題例 |
| :--- | :--- | :--- |
| NORMAL | ウェルノウンポート (0〜1023) | 初心者向け。HTTP、HTTPS、SSH、DNSなど、非常に有名な基礎ポートのみを厳選。 |
| HARD | ウェルノウンポート (0〜1023) | 中級者向け。DHCP、SNMP、BGP、Syslogなどのマイナーなインフラ系プロトコルも含む全ウェルノウン。 |
| OMAKE (ALL) | 0〜65535 (全範囲) | 上級者・開発者向け。MySQL、Next.js、Minecraft、Redisなどの開発・DB・ゲーム系ポートも含めた全データ。 |

## 使用技術・ライブラリ

このプロジェクトは、ビルドツールやフレームワークを必要とせず、モダンなWeb技術とCDN経由の軽量ライブラリのみで構築されています。

- コア技術: HTML5, CSS3, JavaScript (ES6+ Modules / Async-Await)
- UI・ダイアログ: SweetAlert2 (サイバーパンク風のカスタムスタート画面・結果発表)
- アニメーション: Anime.js (制限時間プログレスバー、不正解時の画面揺れ、スコアのカウントアップ)
- パーティクル: Canvas Confetti (コンボ達成・ゲームクリア時の紙吹雪演出)
- オーディオ: Web Audio API (外部音声ファイルを使用せず、ブラウザ内で8bit風のシンセサイザー音を動的生成)
- データ管理: JSONによる問題データの外部分離

## ファイル構成

プロジェクトのディレクトリ構造は以下の通りです。

```text
port-hacker/
├── index.html       # メインのHTML構造とUIパーツの定義
├── style.css        # サイバーパンク風デザイン、スキャンライン、アニメーション定義
├── main.js          # ゲームのコアロジック、ステート管理、タイマー、イベント制御
└── ports.json       # 各モードのポート番号・プロトコル名・解説文のデータベース
```

## ローカル実行方法

外部のJSONファイルを非同期で読み込む仕様上、ローカルファイルを直接ブラウザで開くと、ブラウザのCORSポリシーによりデータが読み込めません。
必ず以下のいずれかのローカルWebサーバー環境経由で起動してください。

1. リポジトリ内の4つのファイルを同じフォルダに配置します。
2. VS Codeを使用している場合は、拡張機能のLive Serverなどをインストールします。
3. index.htmlを右クリックし、Open with Live Serverを選択してブラウザで開きます。

## 操作方法

| 操作対象 | アクション |
| --- | --- |
| マウス / タップ | 選択肢ボタンのクリック、および解説パネルのクリックで次へ進む |
| 1 〜 4 キー | 4択の選択肢を即座に回答する（スタートメニューの選択にも対応） |
| 任意のキー (Enter / Space等) | 解説画面をスキップして次のステージへ即座に移行する |
